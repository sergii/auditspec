# Evidence trust model

Audit data has different evidentiary strength depending on where it was produced.

- `authoritative` - generated by the enforcement or execution boundary.
- `attributed` - generated by a trusted intermediary with a verifiable identity.
- `self_reported` - generated by the actor or actor-controlled runtime.
- `derived` - inferred from other evidence.

A local coding-agent plugin reporting its own tool call is useful telemetry, but it is weaker evidence than a server that actually executed and authorized the tool call.
